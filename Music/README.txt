Drop your music files here (mp3, ogg, wav or m4a).

They are matched by file name when you launch with play.bat:
  intro / title / theme / menu   -> title screen & ending song
  battle / fight / combat        -> battle music       (optional)
  boss / final / kraken          -> final boss music   (optional)
  anything else                  -> map / background music

Examples:  intro.mp3   background.mp3   battle.mp3   boss.mp3

Missing tracks fall back automatically (boss -> battle -> background -> intro).
To choose files by exact name instead, edit js/config.js.
